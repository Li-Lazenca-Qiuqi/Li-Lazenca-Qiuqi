# 个人网站同仓管理需求草案

状态：单幅圣堡室内构图版与本地背景音乐已实现，GitHub Pages 手动发布工作流已配置；用户表示所购原声带可用于个人非商业网站，公开传播授权条款未核验，正式上线待确认。日期：2026-09-26。

## 1. 来源与目标

用户提出“我打算把我的个人主页也放在这个项目里”，并确认要在本项目新建独立网站。

用户补充说明：气象是专业，同时也是热心的开发者和游戏玩家；游戏部分首版只展示玩家身份。网站应平衡这三个侧面，避免让气象意象主导整站视觉。

2026-09-26 用户要求以《空洞骑士：丝之歌》的圣堡为视觉灵感制作个人网页，并表示之后提供背景音乐。随后用户明确要求沿用参考图中的二维手绘氛围，只使用一幅屋顶插画；屋顶下方留出放置内容的空白区域，可使用两侧边框。页面采用原创建筑、雾光与暗色墨绘质感，不直接使用游戏截图、角色或标志。配乐文件当时尚未提供，因此初版没有播放控件。

用户进一步指出首版屋顶画风太写实、形态像悬空桥，且两侧边框不明显。当前实现将屋檐连接到两侧立柱，采用更平面的二维卡通笔触，并把边框贯穿整页。

用户继续要求两侧立柱延伸到页面底端，并为内部留白增加少量背景装饰与更华丽的金色氛围。CSS 拼接版被用户认为观感不佳，当前改为一幅完整的二维手绘室内构图，屋顶、立柱、拱廊和暖金色光源在同一画面内，正文仍保持可读。为支持未来增加内容，同一幅插画按画框切片使用：屋顶和底座保持固定，立柱中段沿页面延伸。

随后用户提供背景音乐文件并要求自动播放。本站在加载时尝试有声播放；浏览器限制自动播放时，在首次点击或按键后重试，同时提供暂停与恢复按钮。用户表示所购原声带可用于个人非商业网站，具体公开传播授权条款未核验。

本项目保留两个清晰的交付物：根目录 `README_.md` 暂存 GitHub 个人资料页草稿，定稿后改回 `README.md`；网站源码放在独立目录，具有自己的本地预览与构建流程。现有 `demo/` 用于近似预览草稿。

## 2. 范围草案

1. 在 `site/` 使用 React、TypeScript 与 Vite 新建可本地运行的网站，网站内容围绕研究、软件开发和游戏玩家三个侧面展开。
2. 首版沿用已有 README 中可审阅的研究与技术线索；游戏部分只陈述用户确认的玩家身份，具体游戏、类型或作品待用户提供。
3. 视觉以个人气质和阅读体验为主，气象元素仅作适量点缀；不把云层、等压线或研究数据作为整站主视觉。
4. README 与网站可以使用经确认的相同个人介绍，但分别维护各自的展示形式；生成脚本不得覆盖另一交付物或用户手工内容。
5. 不根据项目名推断 GitHub 账号、域名、履历、成果或联系方式；对外发布内容均需用户确认。
6. 新视觉使用一幅有实体屋檐的二维手绘插画，两侧立柱持续至页面底端，内部使用适量金色装饰。研究、开发、游戏作为屋顶下方的文字内容呈现，不拆分为三张场景图。背景音乐在本地自动尝试播放并可控制；公开使用范围须在部署前确认。

本草案不授权部署、绑定域名、创建远程仓库、提交 Git 或更新版本。是否需要这些动作，在具体实施阶段依据用户要求确定。
