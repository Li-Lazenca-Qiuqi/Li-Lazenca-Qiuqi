# 001：以 Profile README 作为主页载体

日期：2026-09-12。

状态：已按此路线完成本地 Demo；真实统计、自动化与发布尚未实施。

## 背景与选择

参考聊天讨论的是 GitHub 个人资料页。拟采用 Markdown、GitHub 支持的 HTML 和 SVG 资源，不引入独立 Web 应用构建链。这样可以直接服务个人资料页展示，保持维护步骤较少。

## 资源与增强策略

- Banner、定制徽章优先纳入仓库，便于统一风格和追踪变更。
- 图标来源可考虑 Devicon 或 Simple Icons，使用前核对许可与品牌要求。
- 统计卡片提供方暂不选定；不得默认使用朋友的部署实例。
- 贡献动画拟使用 Platane/snk，生成物拟放在 output 分支，源文件与工作流留在主开发分支。
- 主分支名、Action 版本、权限和生成路径在实施时根据真实仓库确定。
- 工作流只授予必要权限；提交生成物的任务才需要写权限，凭据不进入 README、图片链接或日志。
- 动态服务故障时优先保留最近有效图像或移除失效模块，主体介绍保持可读。

## 代价与后续条件

README 无法等价替代自由布局的网站；最终效果必须在 GitHub 上验收。外部统计服务有可用性与缓存依赖，定时任务也不作为准点运行保证。

用户后续已明确要求在同仓新建个人网站，见[个人网站选型记录](002-personal-site.md)。
