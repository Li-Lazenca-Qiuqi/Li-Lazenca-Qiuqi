# 002：在同仓独立维护个人网站

日期：2026-09-25。

状态：初版已采用并部署到 GitHub Pages；公开内容仍可继续审阅。

## 背景与选择

用户确认要在现有项目中新建个人网站，并要求研究、开发、游戏玩家身份都得到呈现。根目录 Profile 草稿暂存为 `README_.md`，定稿后改回 `README.md`；`demo/` 继续近似预览该草稿，独立网站源码位于 `site/`。

网站使用 React、TypeScript 与 Vite，首版为本地可构建的单页。页面内导航将访客带到研究、开发和游戏章节，具体游戏、账号、域名与联系方式均未加入。

## 维护边界

- `scripts/build_demo.py` 只管理 README 与原有 SVG，不管理 `site/`。
- 网站在 `site/` 内安装依赖和构建；生成的 `node_modules/` 与 `dist/` 由该目录的 `.gitignore` 排除。
- 网站文案和公开资料在正式发布前审阅；托管平台已选 GitHub Pages，使用手动触发的 Actions 工作流部署 `site/dist/`。

## 可增长的画框

网站当前使用一幅原创室内插画作为 `border-image` 来源。九宫格切片固定屋顶和底部装饰，中段仅沿两侧重复立柱；中央正文区使用独立的暗色背景。页面高度由正文决定，新增整宽内容区块时无需拉伸屋顶或重画背景。

研究、开发、游戏三栏只承担简短身份介绍。后续较长的项目、文章或作品内容应作为三栏之后的独立区块加入，避免单栏增长造成另外两栏的大面积空白。图像切片数据与响应式尺寸维护在 `site/src/App.css`。
