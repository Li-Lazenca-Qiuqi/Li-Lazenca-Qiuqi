# 产品现状

更新日期：2026-09-26。

## 产品定位

本项目同仓管理两项交付物：GitHub Profile README 与独立个人网站。README 供 GitHub 资料页展示，`demo/` 用于本地近似预览；`site/` 是面向独立访问的个人网站，介绍研究、开发与游戏玩家三个侧面。

## 现有功能

| 内容 | 当前能力 |
| --- | --- |
| 主页主体 | README 演示稿，含介绍及 Atmospheric Science、Computing、Agent Stack、Developer Tools 四类内容 |
| 气象视觉 | 深浅主题 Banner，采用装饰性等压线意象，不表示真实观测 |
| 工具徽章 | 13 个统一 SVG 徽章，使用文字缩写 |
| 统计展示 | 深浅主题占位卡片，无实际账号数值 |
| 贡献展示 | 深浅主题静态贪吃蛇与合成示例网格，明确标识非真实贡献 |
| 本地预览 | 直接读取 README 渲染，采用 github-markdown-css 5.8.1，支持深浅主题与窄屏容器切换 |
| 内容生成 | 标准库脚本生成 19 个 SVG 与 README；独立渲染脚本读取 README 生成预览 HTML |
| 独立个人网站 | `site/` 内的 React、TypeScript 与 Vite 单页，使用一幅原创二维手绘圣堡室内插画构成可延长的画框；屋顶和底座固定，两侧立柱随正文延伸，前景为研究、开发、游戏文字内容及页面内导航 |

README 当前为可本地审阅的 Demo；个人网站首版也处于本地审阅阶段。公开资料与最终风格尚未定稿，真实统计、贡献动画生成、Actions 调度与正式发布尚未实施。

## 关键流程

1. 依照 [Demo 维护说明](note/demo-preview.md)启动本地服务并打开预览。
2. 审阅介绍、工具清单、深浅主题及窄屏布局。
3. 修改 README 后运行 build_preview.py 刷新预览；只有需要重建内容与素材时才运行 build_demo.py。
4. 运行生成器前核对受管理文件中的人工修改，避免覆盖未整合的用户内容。
5. 重新生成后进行相应检查；确认账号与正式内容后，按 [PRD](PRD/github-profile.md) 和 [TODO](TODO.md)推进后续工作。
6. 独立网站的启动、构建与内容边界见[网站预览说明](note/site-preview.md)；网站源码不由 README 生成脚本管理。

启动与生成命令统一维护在 Demo 说明中。本项目 README 用于主页展示，安装和维护信息不写入该交付物。

## 支持范围

- 开发环境：WSL Ubuntu-E，使用 uv 运行 Python。
- 素材生成仅依赖标准库；预览脚本通过 uv 使用固定版本 markdown-it-py 与 nh3。
- 本地预览为静态文件；主题和窄屏按钮仅在本地预览壳生效。
- README 使用主题图片资源；最终 GitHub 渲染需单独验证。
- 个人网站在 `site/` 内独立运行；目前只有静态介绍和页面内导航，不依赖后端或账号数据。

## 已知限制与验证边界

- GitHub 用户名尚未确认，不能将目录名当作账号。
- 统计未连接真实数据，贡献图静态且为示例；没有自动更新能力。
- 主页文案及徽章清单仍待最终确认，不代表用户已逐项认可。
- 预览是生成时的 README 快照，编辑后需重新生成并刷新；控制栏在正文之外。
- 样式为开源近似，不是 GitHub 官方页面；未复现个人侧栏、全部 GFM 扩展、图片代理和完整过滤流水线。
- 2026-09-12 的本地检查记录见 [Demo 说明](note/demo-preview.md)；未完成 GitHub 正式验收。
- 2026-09-26 已建立本地 Git 仓库；尚未配置远端或对外发布。
- 预览服务是否运行需当时检查，不以历史启动记录作为当前可访问性依据。
- 网站首版文案与视觉待用户审阅；游戏部分目前仅呈现已确认的玩家身份，未加入具体游戏或偏好。
- 旧版分章节插画与屋顶插画仍保留在 `site/public/images/`，当前页面只引用 `citadel-hall-frame.png`。
- 背景音乐文件尚未提供，网站目前没有音频播放功能。
- 网站尚未部署，域名和托管方式未确认；本地构建与浏览器检查记录见[网站预览说明](note/site-preview.md)。
