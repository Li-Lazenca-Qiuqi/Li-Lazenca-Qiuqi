# 个人网站预览与维护

建立日期：2026-09-25。

## 范围

`site/` 是独立个人网站的 React、TypeScript、Vite 源码。根目录 `README_.md` 暂存 GitHub Profile 草稿，不在资料页展示；`demo/` 只预览该草稿。两个交付物各自运行，不共享构建输出。

首版网站介绍研究、软件开发与游戏玩家身份。游戏部分只陈述用户确认的玩家身份。页面没有真实统计、具体游戏清单、联系方式或账号链接；文案与视觉仍待审阅。

## 本地运行

在 WSL Ubuntu-E 中进入 `site/` 后执行：

```bash
npm install
npm run dev
```

在 Windows 上打开 `http://localhost:5180/`。Vite 固定使用 5180 端口，若该端口被占用会直接报错，避免悄悄切换到其他地址。生产构建与 TypeScript 检查：

```bash
npm run build
npm run check
```

构建产物位于 `site/dist/`，该目录与 `site/node_modules/` 均已由 `site/.gitignore` 排除。网站内容在 `site/src/App.tsx`，样式在 `site/src/App.css` 与 `site/src/index.css`；背景音乐组件及样式分别在 `site/src/BackgroundMusic.tsx` 与 `site/src/BackgroundMusic.css`。
